# 오늘 목록 빈 상태 두 갈래 (+ 자정 힌트)

## 무엇을

오늘 목록이 비었을 때, 이번 주 Sprint 가 있는지로 안내를 나눈다.

- Sprint 가 있을 때 — Sprint 에서 할 일을 가져오라는 안내
- Sprint 가 없을 때 — `계획이 없어도 타이머는 돌아가요` + `자유 집중 시작` 고스트 버튼
  (집중이 대기 중일 때만)

## 왜

- 지금은 한 갈래뿐이다 — `TodayList.tsx` 가 `오늘 몫이 비어 있어요` 하나만 그리고,
  `자유 집중 시작` 버튼도 없다.
- 스펙: [today-tasks PRD](../features/today-tasks/prd.md) R19~R22·A19,
  [app-shell ux-spec](../features/app-shell/ux-spec.md) §7.2 표, app-shell R32.

## 왜 아직 안 만들었나

M2 때는 주간 카드가 없어서 한 갈래만 넣고 "week-plan 구현 시 복원한다"고 계획서에만 적었다.
그 뒤 week-plan 이 들어왔지만 복원되지 않았다.

## 먼저 풀 문제

R20 카피 원문이 낡았다. #85 가 `+ 오늘로` 버튼을 없애 가져오는 진입점이 드로어 하나가 됐고,
#86 이 `주간 할당` 을 Sprint 로 바꿨다. 카피부터 다시 써야 한다.
