# 앱 마우스 드래그 방지

## 무엇을

앱 창(또는 특정 영역)을 마우스 드래그로 움직이거나 선택되지 않게 막는다.

## 왜

- 타이머 조작 중 의도치 않게 창이 끌려가거나 텍스트가 드래그 선택되는 것을 방지.

## 구현 아이디어 (미확정)

- 텍스트/요소 선택 방지: 전역 CSS `user-select: none` (입력 필드는 예외).
- 창 이동 방지: Electron `BrowserWindow` 의 `movable: false`, 또는
  드래그 가능 영역(`-webkit-app-region: drag`)을 타이틀바 등 일부로 한정.
- 이미지·링크의 기본 드래그(고스트 이미지)는 `draggable=false` / `dragstart` 방지로 처리.

## 열린 질문

- 막을 대상이 "창 이동"인지 "요소 드래그 선택"인지, 둘 다인지 확정 필요.
