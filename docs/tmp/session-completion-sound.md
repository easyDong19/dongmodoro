# 세션 완료 알림음

## 무엇을

세션(집중/휴식)이 끝날 때 소리를 낸다.

## 왜

- **명세는 이미 있는데 구현이 없다.** [timer prd.md](../features/timer/prd.md) R11 이
  `알림음과 OS 알림을 보낸다` 라고 쓰고 [ux-spec §6.1](../features/timer/ux-spec.md) 도
  알림음을 함께 적어 뒀지만, 저장소에 오디오 재생 코드가 한 줄도 없다.
  2.2.0 에서 Dock 바운스를 넣으면서 확인된 사실이다.
- 소리는 화면을 안 보고 있을 때 가장 먼저 닿는 신호다. Dock 바운스는 시선을 끌지만
  화면 자체를 안 보고 있으면(다른 일을 하고 있으면) 아무 역할을 못 한다.

## 왜 2.2.0 에 넣지 않았나

겉보기보다 딸려 오는 것이 많다 — 소리 파일 에셋(라이선스·포맷·패키징 포함), 볼륨,
**끌 수 있는 설정**, 그리고 그 설정을 둘 자리. 앱에는 아직 사용자 설정 화면이 없고
(`docs/features/` 에 settings 기능 폴더가 없다) 알림을 끄는 스위치도 없다.
Dock 바운스와 한 PR 로 묶으면 릴리스가 그만큼 밀린다고 판단해 분리했다.

## 구현 아이디어 (미확정)

- 재생 위치: main 프로세스에는 오디오 API 가 없다. 렌더러에서 `Audio` 로 재생하거나
  `shell.beep()` 를 쓰는 두 갈래. 후자는 파일이 필요 없지만 소리를 고를 수 없다.
- 완료 판정은 main 이 소유하므로(prd R12), 렌더러 재생이라면 `timer:transition` ·
  `session:recorded` 중 어느 이벤트에 붙일지 정해야 한다 — 창이 닫혀 있으면 렌더러가
  없다는 점이 이 선택의 핵심이다.

## 열린 질문

- 끄는 설정을 어디에 두는가. 설정 화면이 없으므로 이 항목이 그 화면을 요구할 수 있다.
- 집중 완료와 휴식 완료의 소리를 다르게 할지 (ux-spec §6.2 는 주의 신호를 같은 강도로
  다루기로 정했다 — 소리도 같은 판단을 따를지는 별개다).
- 시스템 알림음(OS 알림에 딸린 소리)과 겹치지 않는지. 겹치면 두 번 울린다.
