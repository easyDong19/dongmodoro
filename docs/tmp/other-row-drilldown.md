# 기타 행 드릴다운

## 무엇을

주간 카드의 `기타 — 계획에 없던 집중` 행에 캐럿을 달아 **읽기 전용** 드릴다운을 연다.
두 그룹으로 나눈다.

- `이름을 남긴 것` — 소급 생성·직접 추가한 task 의 제목과 측정 시간
- `이름 없는 집중` — 어떤 할 일에도 연결되지 않은 세션의 합계 한 줄

생성·pull·완료·폐기 조작은 두지 않는다.

## 왜

- 기타 행은 총합만 보여서, "계획에 없던 집중"이 무엇이었는지 되짚을 수 없다.
- 스펙은 이미 있다 — [week-plan PRD](../features/week-plan/prd.md) R17 마지막 하위 항목·A22 뒷절,
  [ux-spec](../features/week-plan/ux-spec.md) §3.4(캐럿 행)·§6.4 표. 통화가 측정 시간으로 바뀐
  뒤에도 스펙은 시간 기준으로 고쳐져 있다.

## 왜 아직 안 만들었나

M3a·M3b 모두 "새 IPC 채널 + 상관 서브쿼리로 읽기 전용 이름 목록 하나를 만드는 일이고, 총합은
드릴다운 없이도 보인다"는 이유로 뺐다. 기다리는 선행 조건은 없다 — 언제 붙여도 된다.
현재 코드에는 `WeekCard.test.tsx` 의 테스트 이름("기타 행에는 캐럿이 없다")으로만 흔적이 있다.
