창을 화면 절반에 두고 써도 타이머가 남습니다. 좁은 창에서는 Milestone 과 캘린더가 접히고,
필요할 때 타이틀바의 `MONTH` 버튼으로 열어 봅니다.

## 새로 생긴 것

- **좁은 창에서 타이머가 짓눌리지 않습니다.** 전에는 창을 줄이면 가운데 타이머 카드만
  줄어들어, 화면을 반으로 갈라 쓰면 남은 시간과 시작 버튼이 세로 막대처럼 뭉개졌습니다.
  이제 창이 좁아지면 Milestone·캘린더 컬럼이 먼저 접히고 타이머가 자리를 물려받습니다.
- **`MONTH` 버튼으로 접힌 컬럼을 엽니다.** 좁은 창에서만 타이틀바에 나타납니다. 누르면
  Milestone 과 캘린더가 오른쪽에서 Sprint·오늘 목록 위를 덮습니다. 열려 있는 동안에도
  타이머는 가려지지 않고 그대로 조작됩니다. 닫는 방법은 `MONTH` 다시 누르기, `Esc`,
  오른쪽 위 닫기 버튼 세 가지입니다.
- **창을 넓혔다 좁혀도 보던 달이 유지됩니다.** 캘린더를 지난달로 옮겨 둔 채 창 크기를
  바꿔도 이번 달로 돌아가지 않고, 쓰던 Milestone 입력도 남습니다.

## 고친 것

- **Sprint 제목을 한글로 치고 Enter 를 누르면 항목이 하나만 생깁니다.** 전에는 두 개가
  생겼습니다 — `가나다라` 를 입력하면 `가나다라` 와 `라` 가 함께 만들어졌습니다. 한글 조합
  중에 눌린 Enter 를 앱이 두 번으로 세던 문제이고, 영문 입력에서는 나타나지 않았습니다.

## 알아 둘 것

- **Milestone 의 보관 기능이 없어졌습니다.** 보관 버튼과 접혀 있던 보관 목록, 배지 옆
  숫자가 사라집니다. 전에 보관해 둔 항목은 **없어지지 않고 원래 달의 목록에 다시
  나타납니다.** 달성 배지의 `N/M` 은 그대로입니다 — 분모는 원래 보관 여부와 무관했습니다.
- **지난 달의 Milestone 카드는 읽기 전용입니다.** 이름 수정·완료 표시·삭제 버튼이 지난
  달에는 나오지 않습니다.
- **창을 720px 보다 좁게 줄일 수 없습니다.** 그보다 좁은 폭을 위한 1컬럼 화면은 아직
  없어서, 화면이 깨진 채로 쓰이지 않도록 창 크기에 하한을 두었습니다.

## 업그레이드 — **되돌릴 수 없다**

2.4.0 은 앱을 처음 켤 때 DB 마이그레이션을 돌린다. `milestones` 테이블의 `archived_at`
컬럼이 **삭제**된다. 보관해 둔 Milestone 항목의 행 자체는 보존되며, 보관 표시만 사라져
원래 달의 목록에 다시 나타난다. 세션·할 일·Sprint·캘린더 기록은 영향을 받지 않는다.

### 시작하기 전에

1. **2.3.0 설치 파일(`.dmg`)을 따로 보관한다.** 지금 받아 두거나
   [Releases](https://github.com/easyDong19/dongmodoro/releases) 에서 다시 받을 수 있는지
   확인한다. 이유는 아래 §복귀선.
2. 앱은 마이그레이션 **직전에 DB 백업을 자동으로 만든다.** 위치는 macOS 기준
   `~/Library/Application Support/dongmodoro/` (앱의 `userData` 폴더)이고 파일명은
   `app.db.backup-<시각>` 이다. 최근 5개까지 보관된다.
3. 걱정되면 그 폴더의 `app.db` 를 안전한 곳에 **직접 한 벌 더 복사해 둔다.** 자동 백업은
   보관 개수 제한이 있지만 손으로 복사한 사본은 없다.

### 복귀선 — 백업 파일 하나로는 되돌아가지지 않는다

**백업 파일만 제자리에 되돌려 놓고 2.4.0 을 다시 켜면, 같은 마이그레이션이 그 백업에
그대로 다시 적용된다.** 앱은 스키마 버전을 보고 판정하므로 되돌린 DB 를 "아직 안 올린 DB"
로 보고 또 올린다.

**실질 복귀선은 조합 하나뿐이다:**

> **백업 파일 + 2.3.0 설치 파일**

되돌리는 순서:

1. 2.4.0 을 종료한다.
2. `~/Library/Application Support/dongmodoro/app.db` 를 백업 파일
   (`app.db.backup-<시각>`)로 교체한다. `app.db-wal`·`app.db-shm` 이 있으면 함께 지운다.
3. **2.3.0 을 설치해서** 연다. 2.4.0 을 다시 열면 1번으로 돌아간다.

2.3.0 설치 파일이 없으면 되돌아갈 방법이 없다. 그래서 §시작하기 전에 1번이 이 노트의
가장 중요한 줄이다.

### 마이그레이션이 실패하면

앱이 켜지지 않고 실패 대화가 뜬다. **백업을 자동으로 복원하지 않는다** — 어느 쪽이 옳은
데이터인지 앱이 판단할 수 없기 때문이다. 대화에서 백업 폴더를 바로 열 수 있고,
위 3단계로 2.3.0 에 복귀할 수 있다.

마이그레이션은 성공한 직후·버전을 올리기 전에 무결성 검사(`foreign_key_check`)를 한 번 더
돌린다. 여기에 걸리면 버전이 올라가지 않으므로 다음 실행에서 다시 시도한다.

## 설치

`.dmg` 를 받아 `dongmodoro.app` 을 응용 프로그램 폴더로 옮긴 뒤, **첫 실행 전에 한 번만**:

```
xattr -dr com.apple.quarantine /Applications/dongmodoro.app
```

서명·공증을 받지 않아서 macOS 가 기본으로 막습니다.
