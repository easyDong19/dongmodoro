세션이 끝난 것을 다른 일을 하다가도 알 수 있게 됐습니다. 뽀모 길이를 `±` 로 조절하면
그것이 곧 저장되는 값이 되고, 정산 패널에 있던 길이 편집은 없어졌습니다.

## 새로 생긴 것

- **세션이 끝나면 Dock 아이콘이 튑니다.** 앱이 다른 창에 가려져 있을 때만 시작하고, 앱으로
  돌아오는 순간 멈춥니다. 그때까지는 계속 튑니다 — 한 번만 튀면 마침 화면을 안 보고 있던
  경우에 놓치기 때문입니다. 전에는 앱이 뒤에 있으면 세션이 끝난 것을 알 방법이 알림 하나뿐
  이었습니다.

## 고친 것

- **`±` 로 조절한 뽀모 길이가 저장됩니다.** 집중을 30분으로 맞추고 휴식을 다녀오면 다시
  25분으로 돌아가 있던 것을 고쳤습니다. 조절한 그 값이 그 모드의 기준이 되고, 앱을 껐다
  켜도 남습니다. 조절은 대기 중에만 할 수 있고, 세션이 도는 동안에는 `±` 가 비활성입니다.
- **버튼과 라벨의 글자가 드래그로 선택되지 않습니다.** `±` 칩이나 테마 세그먼트를 연타할 때
  글자가 파랗게 잡히던 것을 고쳤습니다.

## 알아 둘 것

- **정산 패널에서 뽀모 길이를 고치는 자리가 없어졌습니다.** 조절이 곧 저장이 되면서 그
  기능의 자리는 타이머 카드의 `±` 하나가 됩니다. 정산 패널에 있던 편집 폼과 현재 길이 표시가
  함께 사라졌습니다.
- **길이 저장이 실패하면 아무 표시가 나오지 않습니다.** 실패를 알리던 문구가 사라진 편집
  폼에 있었습니다. 이 경우 화면의 숫자는 바뀌어 보여도 저장된 값은 그대로입니다 — 앱을 다시
  열면 저장된 값이 나옵니다.
- **앱을 보고 있을 때는 Dock 이 튀지 않습니다.** 알림은 그때도 옵니다.
- **글자를 드래그해 복사하는 것은 입력란에서만 됩니다.** 목록의 제목이나 화면의 문구는
  드래그로 선택되지 않습니다.

## 설치

`.dmg` 를 받아 `dongmodoro.app` 을 응용 프로그램 폴더로 옮긴 뒤, **첫 실행 전에 한 번만**:

```
xattr -dr com.apple.quarantine /Applications/dongmodoro.app
```

서명·공증을 받지 않아서 macOS 가 기본으로 막습니다.
