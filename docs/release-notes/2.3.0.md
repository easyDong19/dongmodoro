주간 계획을 쪼개는 손이 편해졌습니다 — task 를 여러 개 연달아 만들고 한 번에 오늘로
가져올 수 있고, Milestone 은 어느 미래 달이든 날짜 제한 없이 계획할 수 있습니다.

## 새로 생긴 것

- **task 를 여러 개 연달아 만들 수 있습니다.** Sprint 항목을 펼친 뒤 입력창에서 Enter 를
  칠 때마다 task 가 목록에 쌓입니다. 전에는 한 번에 하나만 만들 수 있었고, 만드는 순간
  오늘 목록으로 가 버려서 세 개를 쪼개려면 같은 화면을 세 번 열어야 했습니다.
- **가져오기는 체크박스로 골라 버튼 한 번입니다.** 방금 만든 task 는 체크된 채로 쌓이고,
  내일 몫은 체크만 풀면 task 로 남습니다. `오늘로 가져오기 (n)` 버튼이 몇 개를 가져가는지
  숫자로 보여줍니다.
- **Milestone 을 어느 미래 달이든 계획할 수 있습니다.** 전에는 다음 달까지만 열렸고 그
  너머는 "N월 1일부터 계획할 수 있어요"로 막혀 있었습니다. 이제 캘린더로 몇 달을 넘겨도
  계획을 잡을 수 있습니다. 지난 달이 읽기 전용인 것은 그대로입니다.
- **화면 용어가 바뀌었습니다.** `결과물` 은 `Milestone` 으로, `이번 주 할당` 은 `Sprint`
  로, `조각` 은 `task` 로 부릅니다. 데이터는 그대로이고 이름만 바뀝니다.

## 고친 것

- **목록이 길어져도 카드 밖으로 넘치지 않습니다.** 오늘 목록·Milestone 의 내용이 카드
  경계를 뚫고 그려지던 것을 고쳤습니다 — 이제 카드 안에서 스크롤합니다. 할 일을 바로
  추가하는 입력창은 목록이 아무리 길어도 카드 아래에 남습니다.
- **Milestone 카드가 자라며 캘린더를 밀어내지 않습니다.** 카드 높이는 창 크기에서만
  정해지고, 항목을 몇 개 넣든 이웃 카드가 움직이지 않습니다.
- **가져오기 알림이 화면 오른쪽 아래에 불투명하게 뜹니다.** 전에는 반투명이라 아래
  내용과 겹쳐 보였습니다.

## 알아 둘 것

- **Sprint 항목 행의 `+ 오늘로` 버튼이 사라졌습니다.** 없어진 게 아니라 한 곳으로
  모았습니다 — 행을 펼치면 나오는 화면이 가져오기의 유일한 입구입니다. 버튼 두 개가
  같은 일을 다르게 해서 헷갈리던 것을 정리했습니다.

## 설치

`.dmg` 를 받아 `dongmodoro.app` 을 응용 프로그램 폴더로 옮긴 뒤, **첫 실행 전에 한 번만**:

```
xattr -dr com.apple.quarantine /Applications/dongmodoro.app
```

서명·공증을 받지 않아서 macOS 가 기본으로 막습니다.
