# 릴리스 노트 2.0.1 — 목록이 손끝에서 흔들리지 않는다

> **이 파일의 자리.** [2.0.0 노트](2.0.0.md) 머리말과 같다 — 자동 생성되는 draft 본문은
> 커밋 목록뿐이므로, publish 전에 사람이 이 글을 draft 위에 붙여 넣는다.

## 무엇이 바뀌었나

**전부 화면 동작 수정이다.** 데이터 모델·스키마·마이그레이션은 2.0.0 과 같고, 새 기능은
없다.

- **세션 중에는 오늘 할 일을 치울 수 없다.** 타이머가 도는 동안 `치우기`(X) 버튼이
  나오지 않는다. 전에는 세션 중에 눌리는데 타이머는 계속 돌아, 시간을 재고 있던 할 일만
  목록에서 사라졌다.
- **오늘 목록의 행이 두 줄이 됐다.** 제목이 한 줄을 온전히 쓰고, 출처 항목과 측정 시간이
  그 아래 줄로 내려갔다. 전에는 한 줄에 다 넣느라 **부모 항목 제목이 길면 정작 읽어야 할
  할 일 제목이 잘렸다.**
- **완료 체크박스를 앱의 다른 컨트롤과 같은 모양으로 바꿨다.** 운영체제 기본 체크박스가
  어두운 배경 위에서 흰 사각형으로 떠 행에서 가장 눈에 띄는 요소가 돼 있었다. 오늘
  목록·항목 드로어·마일스톤 가져오기 세 곳이 함께 바뀌었다.
- **타이머를 켜고 꺼도 할 일 제목의 폭이 그대로다.** 재생·치우기 버튼이 사라지는 구간에도
  그 자리를 비워 둔다. 전에는 세션을 시작하는 순간 제목이 쓸 수 있는 폭이 넓어졌다가
  끝나면 다시 좁아져, 읽던 줄이 그 자리에서 잘리거나 늘어났다.
- **마지막 할 일을 체크해도 아래 내용이 밀리지 않는다.** 비어 버린 목록이 자리를 차지하던
  것을 고쳤다.
- **달을 넘기거나 결과물을 추가해도 화면이 덜컹이지 않는다.**

## 알아 둘 것

- **기록은 그대로다.** 이 릴리스는 저장하는 값을 바꾸지 않으므로 마이그레이션이 없고,
  따라서 **복귀선(백업·되돌리기 절차)이 필요한 릴리스가 아니다.** 2.0.0 에서 올라온
  데이터는 그대로 쓰인다.
- **2.0.0 을 건너뛰고 올라오는 경우**에는 2.0.0 의 파괴적 마이그레이션이 그대로 적용된다.
  그 절차와 복귀선은 [2.0.0 노트](2.0.0.md) 가 소유하며, 이 파일이 대신하지 않는다.
