데이터를 통째로 비우는 길이 앱 안에 생겼습니다. 오늘 목록이 손끝에서 흔들리던 것들도
함께 고쳤고, 저장되는 값은 2.0.0 과 같습니다.

## 새로 생긴 것

- **모든 데이터를 앱에서 지울 수 있습니다.** 화면 위쪽 메뉴 막대의 `데이터` → `모든 데이터
  초기화…` 입니다. 확인 창에서 한 번 더 물은 뒤, 지우기 직전 상태를 백업 파일로 남기고
  앱이 처음 상태로 다시 시작합니다. 전에는 데이터 파일이 있는 폴더를 직접 찾아가 지우는
  방법밖에 없었습니다.
- **앱 메뉴 막대가 생겼습니다.** 그동안 화면 위쪽에 떠 있던 것은 앱이 만든 메뉴가 아니라
  기본값이었습니다. 이제 보기·창·편집 메뉴가 앱의 것이고, 초기화가 그 안에 들어갑니다.

## 고친 것

- **스크롤바가 화면에 맞는 모양이 됐습니다.** 얇은 막대로 바뀌고, 마우스를 올리면 조금
  진해집니다. 전에는 운영체제 기본 스크롤바가 그대로 얹혀 어두운 화면 위에 회색 막대가
  떴습니다. 목록이 길어져 스크롤바가 나타날 때 옆 내용이 밀리던 것도 함께 고쳤습니다.
- **세션 중에는 오늘 할 일을 치울 수 없습니다.** 타이머가 도는 동안 `치우기` 버튼이
  나오지 않습니다. 전에는 세션 중에 눌리는데 타이머는 계속 돌아, 시간을 재고 있던 할 일만
  목록에서 사라졌습니다.
- **오늘 목록의 행이 두 줄이 됐습니다.** 제목이 한 줄을 온전히 쓰고, 출처 항목과 측정
  시간이 아래 줄로 내려갔습니다. 전에는 한 줄에 다 넣느라 부모 항목 제목이 길면 정작
  읽어야 할 할 일 제목이 잘렸습니다.
- **완료 체크박스가 앱의 다른 컨트롤과 같은 모양이 됐습니다.** 운영체제 기본 체크박스가
  어두운 배경 위에서 흰 사각형으로 떠 행에서 가장 눈에 띄는 요소가 돼 있었습니다.
- **타이머를 켜고 꺼도 할 일 제목의 폭이 그대로입니다.** 재생·치우기 버튼이 사라지는
  구간에도 그 자리를 비워 둡니다. 전에는 세션을 시작하는 순간 제목 폭이 넓어졌다가 끝나면
  다시 좁아져, 읽던 줄이 그 자리에서 잘리거나 늘어났습니다.
- **마지막 할 일을 체크해도 아래 내용이 밀리지 않습니다.** 비어 버린 목록이 자리를
  차지하던 것을 고쳤습니다. 달을 넘기거나 마일스톤을 추가할 때 덜컹이던 것도 함께
  고쳤습니다.

## 알아 둘 것

- **초기화는 되돌릴 수 없습니다.** 주간 할당, 할 일, 집중 기록, 마일스톤, 설정이 모두
  사라지고 테마도 기본값으로 돌아갑니다. 대신 지우기 직전 상태가 백업 파일로 남습니다 —
  위치는 확인 창에 함께 보여주며, 앱이 자동으로 되돌려 주지는 않습니다.
- **초기화는 macOS 메뉴 막대에서만 닿습니다.** Windows·Linux 는 앱이 창 제목줄을 직접
  그리는 구조라 메뉴 막대가 화면에 나타나지 않습니다.
- **기록은 그대로입니다.** 저장하는 값을 바꾸지 않았으므로 마이그레이션이 없고, 되돌리기
  절차도 필요 없습니다.
- **2.0.0 을 건너뛰고 올라온다면** 2.0.0 의 마이그레이션이 그대로 돕니다. 그 절차와
  복귀선은 [릴리스 노트 2.0.0](https://github.com/easyDong19/dongmodoro/releases/tag/v2.0.0)
  에 있습니다.

## 설치

`.dmg` 를 받아 `dongmodoro.app` 을 응용 프로그램 폴더로 옮긴 뒤, **첫 실행 전에 한 번만**:

```
xattr -dr com.apple.quarantine /Applications/dongmodoro.app
```

서명·공증을 받지 않아서 macOS 가 기본으로 막습니다.
