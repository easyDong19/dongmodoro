# dongmodoro 2.0 — 진행의 통화가 측정 시간이 된다
## 무엇이 바뀌었나

**계획 시점에 숫자를 입력하는 자리가 앱에서 사라졌다.** 예상 뽀모·주간 예산·요일별 가용량이
전부 없어지고, 화면의 모든 진행 숫자는 **완료된 focus 세션에서 타이머가 실제로 돈 시간의
합**(측정 시간)이 됐다.

- **주간 계획** — 항목을 제목으로만 잡는다. 예상 뽀모 스테퍼·주간 예산 입력·과적 경고·
  요일별 부하 막대가 사라졌다. 요일 배치와 마일스톤 연결은 그대로다.
- **주간 카드** — 하단 예산 게이지가 사라지고, 헤더에 그 주의 측정 시간 합이 붙었다.
  항목마다 그 주에 집중한 시간이 표시된다.
- **오늘 목록·마일스톤 롤업** — 뽀모 도트와 `3/8` 표기가 측정 시간으로 바뀌었다.
- **주간 정산** — 남은 항목의 처분이 **3택에서 2택**(`다음 주로` · `보내주기`)이 됐다.
  줄일 대상인 예상 뽀모가 없어져 `줄여서` 가 성립하지 않는다. 요약에서 `계획 대비` 가
  빠지고 사실만 남는다. 이월 규모는 시간이 아니라 **건수**로 말한다.
- **뽀모 길이 편집** — 저장이 **즉시** 효력을 갖는다. 진행 중인 세션만 원래 길이로 끝나고
  다음 세션부터 새 길이가 적용된다. "다음 주부터 적용" 이라는 지연이 없어졌다.
- **캘린더는 그대로 `집중 N회`** 로 남는다. 의도된 예외이며 근거는
  [calendar-records PRD](https://github.com/easyDong19/dongmodoro/blob/v2.0.0/docs/features/calendar-records/prd.md) 의 "캘린더의 통화" 절에 있다.

과거 기록은 **소급해서 시간으로 읽힌다** — `duration_sec` 는 1.0.0 부터 모든 세션에
저장돼 있었으므로, 예전 주를 열어도 그 주의 측정 시간이 그대로 나온다.

**바뀌지 않은 것:** 세션 기록·완료 판정·알림, 캘린더 점과 공부한 날 수, 마일스톤과 달력의
달 동기, 테마, 창·종료 동작.

## 알아 둘 동작 두 가지

시간을 통화로 쓰면 다음 두 가지가 눈에 띄게 된다. **둘 다 의도된 동작이고 2.0.0 에서
바꾸지 않았다** ([ADR-031](https://github.com/easyDong19/dongmodoro/blob/v2.0.0/docs/architecture/decisions/adr-031-settlement-without-est.md) §3).

- **중단한 세션의 시간은 남지 않는다.** 초기화·모드 탭 전환·앱 종료로 버려진 세션은 기록이
  만들어지지 않으므로 20분을 집중했어도 0분이다. 막는 확인 대화를 넣지 않았다 — 이 앱은
  조작을 가로막지 않는다.
- **자리를 비운 채 만료된 세션은 길이 전부가 잡힌다.** 이 앱의 측정 시간은 스톱워치가
  아니라 "타이머가 돈 시간"이다.

진행 중인 세션의 경과는 완료 전까지 어느 화면에도 더해지지 않는다. 타이머 카드의
카운트다운이 유일한 진행 표시다.

## 업그레이드 — **되돌릴 수 없다**

2.0.0 은 앱을 처음 켤 때 DB 마이그레이션을 돌린다. `weeks` 테이블과 `est_pomos` 컬럼 2개가
**삭제**되고, `sessions.local_week` 의 외래 키가 제거된다. 세션·항목·조각·마일스톤 기록은
전부 보존된다.

### 시작하기 전에

1. **1.1.0 설치 파일(`.dmg`)을 따로 보관한다.** 지금 받아 두거나
   [Releases](https://github.com/easyDong19/dongmodoro/releases) 에서 다시 받을 수 있는지
   확인한다. 이유는 아래 §복귀선.
2. 앱은 마이그레이션 **직전에 DB 백업을 자동으로 만든다.** 위치는 macOS 기준
   `~/Library/Application Support/dongmodoro/` (앱의 `userData` 폴더)이고 파일명은
   `app.db.backup-<시각>` 이다. 최근 5개까지 보관된다.
3. 걱정되면 그 폴더의 `app.db` 를 안전한 곳에 **직접 한 벌 더 복사해 둔다.** 자동 백업은
   보관 개수 제한이 있지만 손으로 복사한 사본은 없다.

### 복귀선 — 백업 파일 하나로는 되돌아가지지 않는다

**백업 파일만 제자리에 되돌려 놓고 2.0.0 을 다시 켜면, 같은 마이그레이션이 그 백업에
그대로 다시 적용된다.** 앱은 스키마 버전을 보고 판정하므로 되돌린 DB 를 "아직 안 올린 DB"
로 보고 또 올린다.

**실질 복귀선은 조합 하나뿐이다:**

> **백업 파일 + 1.1.0 설치 파일**

되돌리는 순서:

1. 2.0.0 을 종료한다.
2. `~/Library/Application Support/dongmodoro/app.db` 를 백업 파일
   (`app.db.backup-<시각>`)로 교체한다. `app.db-wal`·`app.db-shm` 이 있으면 함께 지운다.
3. **1.1.0 을 설치해서** 연다. 2.0.0 을 다시 열면 1번으로 돌아간다.

1.1.0 설치 파일이 없으면 되돌아갈 방법이 없다. 그래서 §시작하기 전에 1번이 이 노트의
가장 중요한 줄이다.

### 마이그레이션이 실패하면

앱이 켜지지 않고 실패 대화가 뜬다. **백업을 자동으로 복원하지 않는다** — 어느 쪽이 옳은
데이터인지 앱이 판단할 수 없기 때문이다. 대화에서 백업 폴더를 바로 열 수 있고,
위 3단계로 1.1.0 에 복귀할 수 있다.

마이그레이션은 성공한 직후·버전을 올리기 전에 무결성 검사(`foreign_key_check`)를 한 번 더
돌린다. 여기에 걸리면 버전이 올라가지 않으므로 다음 실행에서 다시 시도한다.

## 설치

`.dmg` 를 받아 `dongmodoro.app` 을 응용 프로그램 폴더로 옮긴 뒤, **첫 실행 전에 한 번만**:

```
xattr -dr com.apple.quarantine /Applications/dongmodoro.app
```

서명·공증을 받지 않아서 macOS 가 기본으로 막습니다.
