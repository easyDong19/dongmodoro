창 크기에 맞춰 타이머가 알맞게 커지고, 숫자와 링이 가벼워져 다른 카드를 누르지 않습니다.

## 새로 생긴 것

- **타이머가 창 크기에 맞춰 커집니다.** 전에는 창을 키워도 링과 남은 시간이 그대로여서,
  최대화하면 타이머 카드 가운데에 작은 링만 남았습니다. 이제 카드에 남는 자리만큼 커지고,
  창이 낮으면 아래 조절 버튼이 잘리지 않도록 타이머 쪽이 먼저 줄어듭니다.
- **숫자와 링이 가벼워졌습니다.** 남은 시간 숫자를 가는 글꼴로 바꾸고 링 두께를 줄였습니다.
  기본 창 크기에서 타이머가 화면의 다른 카드와 비슷한 무게로 보입니다. 가장 크게 키워도
  지름 320px 에서 멈춥니다.

## 설치

`.dmg` 를 받아 `dongmodoro.app` 을 응용 프로그램 폴더로 옮긴 뒤, **첫 실행 전에 한 번만**:

```
xattr -dr com.apple.quarantine /Applications/dongmodoro.app
```

서명·공증을 받지 않아서 macOS 가 기본으로 막습니다.
