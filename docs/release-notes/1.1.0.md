월 레이어가 올라왔습니다 — 한 달의 **결과물**과 한 달의 **기록**.

## 새로 생긴 것

- **월 결과물** — 이번 달에 뭘 끝내 놓을지를 제목으로만 적습니다. 수치 입력 칸이 없습니다.
  주간 할당을 결과물에 매달면 이번 주 진행이 `이번 주 3/8` 처럼 **범위 라벨과 함께** 보입니다.
- **달력** — 기록이 있는 날에 점이 찍히고, 날짜를 고르면 그날 뭘 하려 했는지가 복원됩니다.
  집중 4회부터는 진한 점입니다.
- **공부한 날 수** — 타이머 아래에 `이번 주 N일 공부 중`. 연속 일수가 아니라 그 주에
  집중한 날의 수라서, 하루 걸러도 깎이지 않습니다.

두 카드는 달 이동을 공유합니다. 달력의 `‹ ›` 를 누르면 결과물 카드도 같은 달로 갑니다.

## 알아 둘 것

- **기존 데이터는 그대로입니다.** 스키마를 바꾸지 않았습니다 — 필요한 테이블이 처음부터
  있었고, 이번 판이 더한 것은 읽는 경로와 화면입니다.
- **보관은 달성률을 바꾸지 않습니다.** 3개 중 1개 완료한 달에서 나머지를 보관해도
  `1/3` 그대로입니다.
- **넘겨도 막지 않습니다.** 예산 초과에 빨간색도 경고도 없습니다.
- 아직 없는 것: 반응형 레이아웃, 트레이 상주. 창을 닫으면 앱이 종료됩니다.

## 설치

`.dmg` 를 받아 `dongmodoro.app` 을 응용 프로그램 폴더로 옮긴 뒤, **첫 실행 전에 한 번만**:

```
xattr -dr com.apple.quarantine /Applications/dongmodoro.app
```

서명·공증을 받지 않아서 macOS 가 기본으로 막습니다
([ADR-028](https://github.com/easyDong19/dongmodoro/blob/v1.1.0/docs/architecture/decisions/adr-028-code-signing.md)).
