# UX Spec: app-shell

> 출처: docs/origin/pomodoro-mockup-v7.html 전체 레이아웃 + docs/origin/pomodoro-prd.md §4·§3.7 (초안) + [결정 원장](../../decision-log/2026-08-04-planning-session.md) Q16·Q17·Q17-1
> 시각 값은 전부 [tokens.md](../../design-system/tokens.md) 토큰 이름으로 기술한다. 시각 판단이 [principles.md](../../design-system/principles.md) 와 충돌하면 그쪽이 이긴다.
> 구간 경계값은 [ADR-001 (design-system)](../../design-system/decisions/adr-001-breakpoint-tokens.md) 이 소유한다 — 이 문서는 `--bp-wide` · `--bp-medium` 이름으로만 부른다.

## 1. 셸의 구성 요소

| 요소 | 내용 |
|---|---|
| 타이틀바 | 프레임리스 창의 커스텀 바. 좌측 트래픽 라이트 영역 → 앱 이름 → 우측 오늘 날짜 라벨. 이 영역이 창 드래그 핸들 |
| 배경 | `--bg-deep` + `--glow-teal` / `--glow-amber` / `--glow-moss` 라디얼 광원 + 미세 별. **정적 렌더** (장식성 무한 애니메이션 금지 — principles §4) |
| 컬럼 | 유리 카드(`--glass`, `--glass-border`, `--radius-lg`)들의 flex column. 카드 헤더의 eyebrow 라벨은 `--text-2xs` + `--tracking-wider` |
| eyebrow | `MONTH` / `WEEK` / `TODAY` — 컬럼이 어느 레이어인지 알리는 유일한 표지 |
| 트레이 | 창 밖 상주. 창이 닫힌 동안의 유일한 복귀 경로 (§6) |

카드 내부 구성은 각 기능(timer, today-tasks, week-plan, milestones, calendar-records)이
소유한다. 셸은 **자리와 접힘**만 정의한다.

## 2. 와이드 (폭 ≥ `--bp-wide`)

시안 3컬럼 그대로. 창 전체는 스크롤되지 않고 각 카드의 스크롤 영역만 스크롤된다
(PRD R3).

```
┌ 타이틀바 ─────────────────────────────────────────────┐
│ ○○○  Pomodoro                          2026년 8월 4일 │
├───────────────┬───────────────────┬───────────────────┤
│ MONTH         │                   │ WEEK              │
│  마일스톤 카드 │      타이머        │  이번 주 할당 카드 │
│               │   (모드 탭 / 링 /  │  ─────────────    │
│ ─────────────│    MM:SS / 대상 /  │  예산 게이지(하단) │
│  캘린더 카드   │    조절 칩 /       ├───────────────────┤
│  (월 그리드    │    액션 버튼 /     │ TODAY             │
│   + 날짜 패널) │    캡처 바 /       │  오늘 할 일 카드   │
│               │    스트릭)         │  (입력 + 목록)     │
└───────────────┴───────────────────┴───────────────────┘
   계획 레이어           코어 루프          계획 → 실행
```

- 좌 컬럼 = MONTH(마일스톤 카드 + 캘린더 카드), 중앙 = 타이머 단일 카드,
  우 컬럼 = WEEK 카드 + TODAY 카드.
- 캘린더의 `‹ ›` 월 이동이 마일스톤 카드와 동기 전환된다 — 셸은 두 카드를 **같은 컬럼에
  인접 배치**해 그 연동이 시야 안에서 일어나게 한다 (별도 탭·모달을 만들지 않는다).

## 3. 미디엄 (`--bp-medium` 이상 `--bp-wide` 미만)

MONTH 컬럼이 접히고, 타이머와 WEEK/TODAY 가 남는다.

```
┌ 타이틀바 ─────────────────────────────────────────────┐
│ ○○○  Pomodoro   [ MONTH ▸ ]            2026년 8월 4일 │
├───────────────────────────┬───────────────────────────┤
│                           │ WEEK                      │
│         타이머             │  이번 주 할당 카드         │
│      (§2 구성 그대로)      ├───────────────────────────┤
│                           │ TODAY                     │
│                           │  오늘 할 일 카드           │
└───────────────────────────┴───────────────────────────┘
```

### 3.1 MONTH 오버레이 토글

| 항목 | 규칙 |
|---|---|
| 토글 위치 | 타이틀바 우측(날짜 라벨 왼쪽). 라벨 `MONTH` + lucide `PanelLeft` 아이콘 |
| 기본 상태 | 접힘. 미디엄으로 진입할 때 항상 접힌 상태에서 시작 |
| 열림 | 좌측에서 슬라이드-인 오버레이. 폭은 와이드의 MONTH 컬럼 폭 유지, 표면은 `--glass-strong` + `--glass-border` |
| 내용 | 와이드의 MONTH 컬럼 그대로 (마일스톤 카드 + 캘린더 카드) — 내용을 축약하지 않는다 |
| **모달 아님** | 화면 전체를 덮지 않고, 열린 동안에도 타이머·WEEK·TODAY 조작이 가능하다 (PRD R6). 배경을 어둡게 덮는 스크림을 넣지 않는다 |
| 닫힘 | 토글 재클릭 / `Esc` / 오버레이 밖 클릭 |
| 열린 상태 유지 | 열어둔 채 와이드로 넓히면 오버레이가 사라지고 원래 컬럼 자리로 복귀한다 (열림/닫힘 여부가 아니라 "MONTH 가 보였다"가 이어진다) |
| 모션 | 슬라이드-인은 상태 변화 전달이므로 허용. `prefers-reduced-motion: reduce` 시 즉시 표시 |

## 4. 내로우 (폭 < `--bp-medium`)

1컬럼. 타이머 축약형이 상단에 고정되고, 그 아래가 탭 영역이다.

```
┌ 타이틀바 ─────────────────┐
│ ○○○  Pomodoro     8월 4일 │
├───────────────────────────┤
│ 집중   12:34      [ ▶ ]   │  ← 타이머 축약형 (고정, 탭 전환에도 유지)
├───────────────────────────┤
│  오늘  │  주간  │  월간    │  ← 탭
├───────────────────────────┤
│                           │
│   (선택된 탭의 카드 하나)   │  ← 스크롤 영역
│                           │
└───────────────────────────┘
```

### 4.1 타이머 축약형

timer ux-spec §9 가 이 배치의 정의를 셸에 위임했다. 축약형은 **한 줄**이다.

| 슬롯 | 내용 |
|---|---|
| 좌 | 현재 모드 — `집중` / `짧은 휴식` / `긴 휴식` 텍스트. `--text-sm`, `--ink-dim`. 탭 형태가 아니라 **표시 전용** |
| 중 | `MM:SS` — `--font-mono` + tabular-nums. 크기는 `--text-xl` (`--text-display` 는 축약형에 쓰지 않는다) |
| 우 | 시작/일시정지 단일 버튼 (lucide `Play` / `Pause`) |

- **진행률 링은 렌더하지 않는다.** 진행은 상단 고정 바 하단의 1px 진행 인디케이터로만
  암시한다 — 색은 `--teal`, 초과·강조 없음.
- 축약형에서 **하지 않는 것**: 모드 전환, 조절 칩(±1/±5/±10), 초기화, 완료 처리,
  집중 대상 지정. 이 조작들은 `오늘` 탭 안의 전체 타이머 카드에서 한다.
- 사후 캡처 바는 축약형에 붙지 않는다 — `오늘` 탭의 타이머 카드 하단에 나타나고,
  다른 탭에 있을 때 세션이 완료되면 탭을 `오늘` 로 전환하지 않고 캡처 바는 다음
  `오늘` 탭 진입 시 노출된다. 어느 경로든 세션 기록 자체는 이미 저장돼 있다
  (timer ux-spec §5 — 캡처는 이름 붙이기일 뿐).

> ⚠️ 가정: 축약형에 모드 전환을 넣지 않는 것은 한 줄 안에서 3개 탭이 터치 타깃으로
> 성립하지 않는다는 판단이다. 실측 후 모드 전환이 필요하다고 판명되면 축약형 탭
> 대신 `오늘` 탭 진입으로 유도한다.

### 4.2 탭

| 탭 | 담는 것 |
|---|---|
| `오늘` | 타이머 전체 카드 + 오늘 할 일 카드 (기본 선택 탭) |
| `주간` | 이번 주 할당 카드 (예산 게이지 하단 고정 포함) |
| `월간` | 마일스톤 카드 + 캘린더 카드 |

- 기본 선택은 항상 `오늘` — 코어 루프가 첫 화면이다.
- 탭 라벨은 텍스트만. 아이콘을 붙일 경우 lucide 컴포넌트로만 하고 **이모지 금지**
  ([principles §6](../../design-system/principles.md)).
- 활성 탭 강조는 `--glass-strong` + `--ink`, 비활성은 `--ink-dim`.
- 탭 전환은 표시 전환일 뿐이다 — 각 탭의 스크롤 위치·펼침 상태(드로어 등)는 탭을
  떠났다 돌아와도 유지된다.
- 주간 리뷰 배너처럼 특정 카드 상단에 붙는 알림은 그 카드가 있는 탭에 그대로 붙는다.
  배너를 무시해도 전 기능이 정상 동작하므로 셸이 탭을 강제 전환하지 않는다.

## 5. 리사이즈와 상태 보존

구간 전환은 **표시의 재배치일 뿐, 아무 사실도 만들지 않는다.**

| 상태 | 구간 전환 시 |
|---|---|
| 진행 중 타이머 | 영향 없음 — main 이 소유하므로 renderer 재배치와 무관 ([ADR-005](../../architecture/decisions/adr-005-timer-architecture.md)) |
| 입력 중인 텍스트 (오늘 할 일 입력·캡처 바·플래너 필드) | 값 유지. 포커스는 요소가 살아 있으면 유지, 접히는 컬럼 안에 있었다면 해제 |
| 선택된 날짜 (캘린더) | 유지 |
| 열려 있던 드로어·펼침 | 유지 |
| MONTH 오버레이 열림 | 와이드로 넓히면 컬럼 자리로 복귀(§3.1), 내로우로 좁히면 `월간` 탭 선택으로 이어진다 |
| 내로우 탭 선택 | 미디엄·와이드로 넓히면 모든 컬럼이 보이므로 탭 상태는 버려진다. 다시 내로우가 되면 `오늘` 로 초기화 |
| 열려 있던 확인 다이얼로그 | 유지 (종료 확인은 구간과 무관) |

- 구간 전환 도중에 데이터 리페치·mutation 을 트리거하지 않는다.
- 창 폭 이외의 조건(높이·OS·화면 개수)으로 구간을 바꾸지 않는다 (PRD R8).

## 6. 창 닫기·복귀·트레이 (Q16)

### 6.1 창 상태와 앱 상태

| 사용자 행동 | 창 | 앱 | 타이머 |
|---|---|---|---|
| 최소화 | 숨김 | 실행 | 계속 (main) |
| 창 닫기(×) | 닫힘 | **실행** | 계속 (main) |
| 트레이 `창 열기` / OS 알림 클릭 | 복원·포커스 | 실행 | 계속 — 자동 시작 없음 |
| 앱 종료(⌘Q) / 트레이 `종료` | 닫힘 | **종료** | 중단, 진행 중 세션 미기록 |

- 창이 닫힌 동안에도 완료 판정·세션 기록·OS 알림은 main 이 수행한다. 창 닫기는
  **표시를 끄는 것**일 뿐이다.
- 창을 닫을 때 확인·안내를 띄우지 않는다. 종료가 아니므로 잃는 것이 없다.
- 복원 시 renderer 는 main 에서 타이머 스냅샷을 당겨오므로 남은 시간이 정확히 이어진다
  (ADR-005 §4).

### 6.2 종료 확인의 소유권

focus 실행 중 종료 요청 시 확인 1회를 거친다. **다이얼로그의 문구·버튼·조건은
timer ux-spec §7 이 소유한다** — 셸은 여기서 다시 정의하지 않고, 다음 두 가지만 정한다.

1. 확인을 요구하는 **경로가 두 개**다 — ⌘Q(및 앱 종료 메뉴)와 트레이 `종료`. 둘 다
   동일한 확인을 거친다.
2. 창이 닫혀 있는 상태에서 확인이 필요하면 **창을 먼저 복원해** 다이얼로그를 보인다.
   사용자가 못 보는 확인창을 만들지 않는다 (PRD R13).

### 6.3 트레이 메뉴

| 항목 | 동작 | 상태 표기 |
|---|---|---|
| `창 열기` | 창 복원 + 포커스. 창이 이미 열려 있으면 포커스만 | 창이 열려 있으면 비활성 또는 `창 보이기` 로 대체 (TBD) |
| (구분선) | | |
| `종료` | §6.2 의 확인을 거쳐 앱 종료 | — |

- 메뉴 항목에 이모지를 쓰지 않는다. 아이콘이 필요하면 OS 트레이 메뉴가 허용하는
  범위에서 lucide 기반 아이콘 이미지로 만든다 (principles §6).
- 트레이 아이콘 자체의 형태(모노크롬 템플릿 이미지 여부), **남은 시간·모드의 트레이
  표시 방식, 알림음 세부는 TBD** — 결정 원장 §F 미결 항목(M4)이므로 이 문서에서
  확정하지 않는다. 남은 시간 표시는 가산점이며 v1 필수 아님(PRD R18).

> ⚠️ 가정: 트레이 메뉴의 최소 구성을 `창 열기` + `종료` 2항목으로 둔다. 타이머 조작
> (시작/일시정지)을 트레이에 넣을지는 M4 에서 트레이 표시 세부와 함께 판단한다 —
> 지금 넣으면 "창 없이 조작 가능한 범위"라는 별개 설계 결정을 선취하게 된다.

## 7. 콜드 스타트 (§3.7)

첫 실행(계획 0개, 세션 0개)에도 **레이아웃은 완전히 동일하다.** 셸은 카드를 숨기거나
전용 온보딩 화면으로 갈아치우지 않는다.

```
┌───────────────┬───────────────────┬───────────────────┐
│ MONTH         │                   │ WEEK              │
│  (빈 상태 카피 │      타이머        │  (빈 상태 카피     │
│   + CTA)      │   25:00           │   + CTA)          │
│               │   자유 집중        │                   │
│ ─────────────│   [ 시작 ]        ├───────────────────┤
│  캘린더        │                   │ TODAY             │
│  (점 없음,     │   ← 여기만 이미    │  (빈 상태 카피)    │
│   오늘만 강조) │      완전히 동작    │                   │
└───────────────┴───────────────────┴───────────────────┘
```

| 원칙 | 규칙 |
|---|---|
| 타이머 우선 | 타이머는 첫 프레임부터 완전히 동작한다. `자유 집중` 상태로 서 있고, 시작을 누르면 그대로 코어 루프가 돌아간다 (PRD R19·R22) |
| 투어 없음 | 환영 모달·단계별 투어·설정 강요 화면을 만들지 않는다. 각 카드의 빈 상태 카피가 그 카드의 역할을 설명한다 |
| 카피 소유권 | 오늘 목록의 빈 상태 → **today-tasks** / 주간 카드·예산 게이지의 빈 상태 → **week-plan** / 마일스톤 빈 달 → **milestones** / 캘린더·날짜 패널의 기록 없음 → **calendar-records**. 셸은 이 문구들을 복제하지 않는다 |
| 실패 프레임 금지 | 빈 상태에 경고색(`--danger`)·경고 아이콘·"데이터 없음"·"설정이 필요합니다" 금지. 톤은 중립(`--ink-dim` / `--ink-faint`)이고 CTA 는 고스트 버튼 ([principles §1](../../design-system/principles.md)) |
| 정상 상태 | 계획 0개는 오류가 아니라 정상 상태다. 세 컬럼 전부 자리에 있고, 비어 있음이 곧 "아직 안 정했음"으로만 읽힌다 |

- 첫 세션을 완주하면 캘린더에 점 하나, 타이머 하단 스트릭에 첫 문구가 생긴다 —
  계획을 하나도 세우지 않은 경로로도 앱이 자기 결과를 보여준다.
- 미디엄·내로우의 콜드 스타트도 같다. 내로우에서는 `오늘` 탭이 기본이므로 첫 화면이
  타이머 + 빈 오늘 목록이다.

## 8. 모션·아이콘·색

- 배경 광원·별은 정적. 오버레이 슬라이드·탭 전환·구간 전환만 모션을 갖고, 전부
  `prefers-reduced-motion: reduce` 에서 전이 없이 즉시 반영된다 (principles §4).
- 셸의 아이콘(오버레이 토글, 트레이, 축약형 재생/일시정지)은 전부 lucide-react
  컴포넌트. **이모지 금지** (principles §6).
- `--danger` 는 셸 어디에도 쓰지 않는다 — 창 닫기·종료는 데이터를 없애는 행위가
  아니다 (principles §2, timer ux-spec §7 과 동일 판단).
- 색·폰트·radius·브레이크포인트는 토큰 이름으로만 (principles §5).
