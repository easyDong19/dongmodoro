# M2 코어 루프 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) 문법으로 진행을 추적한다.

**Goal:** "오늘 목록에서 할 일을 골라 뽀모를 돌리고, 세션이 기록되고, 도트가 오른다"는 코어 루프 한 줄기를 화면에서 끝까지 통과시킨다. 정산·주간 계획·마일스톤·캘린더·반응형 셸·트레이는 만들지 않는다.

**Architecture:** ADR-025(쿼리 키·무효화 초크포인트)·ADR-026(main→renderer 이벤트 채널) 실행분을 먼저 세우고, 그 위에 할 일 저장 → 오늘 목록 → 타이머를 세로로 쌓는다. 타이머는 main 소유(ADR-005), 세션 기록은 커밋 후 `session:recorded` 이벤트로 renderer 에 도달한다.

**Tech Stack:** M1 스택 그대로 (Electron + electron-vite + React 19 + TS strict, better-sqlite3 + drizzle, zod 4, TanStack Query 5, Tailwind 4 + shadcn/ui, Vitest). 추가: `uuid`(v7 생성).

## Global Constraints

M1 계획의 Global Constraints 가 전부 그대로 적용된다 (pnpm 전용, BrowserWindow 보안 플래그, `handleIpc` 로만 IPC 등록, Drizzle import 는 `src/main/db/` 만, `src/shared/` 순수 TS, 시간은 `src/shared/time/` 초크포인트, 주 시작 월요일, UI 이모지 금지·토큰만, 커밋 영어 Conventional Commits, husky 훅 우회 금지). 여기에 이번 마일스톤부터 적용되는 것:

- **ADR-025**: 쿼리 키는 `keys.ts` 팩토리로만 만든다. 캐시 조작(`invalidateQueries`·`setQueryData` 등 8종)은 초크포인트·리스너 파일 밖에서 금지 (Task 3 이 ESLint 로 강제). 키 속 달력 키는 `useClock()` 또는 이벤트 payload 저장값만 — renderer 에서 재계산 금지.
- **ADR-026**: main 발 이벤트는 `sendEvent`/`subscribe` 헬퍼로만, payload 는 양쪽 parse. **DB 상태를 가리키는 이벤트는 커밋 후에만 발송한다.** raw `webContents.send`·`ipcRenderer.on` 직접 호출 금지.
- **작업 브랜치는 `feature/m2-core-loop` 하나**이며 태스크마다 커밋한다.
- 유효 베이스라인·유효 예산의 결정 순서는 pomo-baseline R10·R11 계약 구현 한 곳에만 존재한다 (R13). 화면·다른 서비스가 폴백을 재정의하지 않는다.

**계획 밖 (이 계획에서 하지 않는 것):** 정산·주간 계획 UI·마일스톤·캘린더 (M3 이후), 반응형 3단계·프레임리스 타이틀바·온보딩 오버레이·트레이 (app-shell 작업 — 이번 빌드는 창 닫기=종료가 정상 상태다, app-shell R25), `settings:changed` 이벤트 (M2 에 main 이 설정을 쓰는 경로가 없다 — 트레이 테마와 함께 온다), `last_settled_week` 계산 부트스트랩 (weekly-review §0.2 소관, M3), 뽀모 길이 편집 UI (pomo-baseline), 크래시 복원.

`src/shared/timer/snapshot.ts` (순수 TS — main·renderer 공유, ADR-005 Consequences):

```ts
export type TimerMode = 'focus' | 'short' | 'long'
export type TimerPhase = 'idle' | 'running' | 'paused'

/**
 * 스냅샷형(`{remainingSec}`)이 아니라 타임스탬프형이다 (ADR-005).
 * running 의 남은 시간은 매번 wall-clock 산술로 파생한다 — 이벤트가 밀려도
 * 다시 그리는 순간 자동 복구되고 누적 오차가 구조적으로 불가능하다.
 */
export type TimerSnapshot = {
  mode: TimerMode
  phase: TimerPhase
  /** epoch ms. running 일 때만 non-null. */
  startedAt: number | null
  /** 현재 세션 전체 길이(초). idle 이면 기준 길이. */
  durationSec: number
  /** paused 일 때만 non-null — 일시정지 순간 박제된 남은 초. */
  pausedRemainingSec: number | null
  taskId: string | null
  /** 집중 대상 제목 (renderer 표시용 — ux-spec §1). */
  taskTitle: string | null
  /** 오늘의 focus 세션 수 — 세션 라벨 `N번째 집중`(ux-spec §4)용. main 이 계산해 싣는다. */
  focusCountToday: number
}

export function remainingSec(s: TimerSnapshot, nowMs: number): number {
  if (s.phase === 'paused') return s.pausedRemainingSec ?? 0
  if (s.phase === 'idle' || s.startedAt === null) return s.durationSec
  return Math.max(0, s.durationSec - Math.floor((nowMs - s.startedAt) / 1000))
}
```

`src/main/ipc/events.ts`:

```ts
import type { BrowserWindow } from 'electron'
import { z } from 'zod'

/**
 * main 발 이벤트의 유일한 발송 경로 (ADR-026 §3). raw `webContents.send` 금지.
 * 발송 직전 parse — main 쪽 버그로 계약과 다른 payload 가 나가면 renderer 가
 * 조용히 undefined 를 렌더하는 대신 여기서 터진다. handleIpc 의 응답 parse 와 대칭.
 */
export function sendEvent<S extends z.ZodTypeAny>(
  win: BrowserWindow,
  channel: string,
  contract: S,
  payload: z.infer<S>
): void {
  if (win.isDestroyed()) return
  const parsed = contract.safeParse(payload)
  if (!parsed.success) {
    throw new Error(`Event payload rejected on ${channel}: ${z.prettifyError(parsed.error)}`)
  }
  win.webContents.send(channel, parsed.data)
}
```

```ts
import { EVENT_CHANNELS } from '@shared/ipc/channels'

function on(channel: string): (cb: (payload: unknown) => void) => () => void {
  return (cb) => {
    const listener = (_e: Electron.IpcRendererEvent, payload: unknown): void => cb(payload)
    ipcRenderer.on(channel, listener)
    return () => ipcRenderer.removeListener(channel, listener)
  }
}

const api: Api = {
  system: { getAppInfo: () => ipcRenderer.invoke(CHANNELS.system.getAppInfo) },
  events: {
    onTimerTransition: on(EVENT_CHANNELS.timerTransition),
    onSessionRecorded: on(EVENT_CHANNELS.sessionRecorded),
    onClockBoundary: on(EVENT_CHANNELS.clockBoundary)
  }
}
```

`events.ts` — 앱 최상단 구독 한 곳 (ADR-026 §4). 수신 직후 parse, 타이머는 **cancel → set** 순서 고정:

```ts
export function subscribeMainEvents(qc: QueryClient): () => void {
  const offTimer = api.events.onTimerTransition((raw) => {
    const snapshot = eventContracts.timerTransition.parse(raw)
    void qc.cancelQueries({ queryKey: keys.timer() })   // in-flight pull 이 push 를 덮는 역전 차단 (ADR-026 §4)
    qc.setQueryData(keys.timer(), snapshot)
  })
  const offSession = api.events.onSessionRecorded((raw) => {
    const payload = eventContracts.sessionRecorded.parse(raw)
    const clock = qc.getQueryData<ClockBoundary>(keys.clock())
    dispatchInvalidation(qc, { type: 'session-recorded', payload, currentDayKey: clock?.dayKey ?? payload.localDate })
  })
  const offClock = api.events.onClockBoundary((raw) => {
    const payload = eventContracts.clockBoundary.parse(raw)
    const previous = qc.getQueryData<ClockBoundary>(keys.clock()) ?? payload
    qc.setQueryData(keys.clock(), payload)
    dispatchInvalidation(qc, { type: 'clock-boundary', payload, previous, currentDayKey: payload.dayKey })
  })
  return () => { offTimer(); offSession(); offClock() }
}
```

```ts
export function useToday() {

  const invalidatePull = (r: { itemWeek: string }) =>

  const addDirect = useMutation({ mutationFn: api.today.addDirect, onSuccess: invalidatePull })
  const remove = useMutation({ mutationFn: api.today.remove, onSuccess: invalidatePull })
  const toggle = useMutation({
    mutationFn: api.today.toggleComplete,
    onSuccess: (r) => dispatchInvalidation(qc, { type: 'task-toggled', payload: { parentWeek: r.parentWeek }, currentDayKey: dayKey })
  })
  return { query, addDirect, remove, toggle }
}
```
