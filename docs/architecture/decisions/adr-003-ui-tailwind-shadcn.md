# ADR-003: UI — Tailwind CSS + shadcn/ui (뼈대만, 스킨 전면 교체)

- 상태: accepted (2026-08-03)

## Context

디자인은 시안 v7 의 글래스모피즘 "밤의 온실" 테마가 기준이고
([design-system/tokens.md](../../design-system/tokens.md) 가 토큰의 유일한 출처),
완성된 CSS(유리 카드, 광원, 액센트)가 이미 존재한다. 따라서 어떤 UI 라이브러리를
고르든 그 라이브러리의 기본 스킨은 버리고 시안의 스킨을 입히게 된다.
라이브러리에서 사야 할 것은 스킨이 아니라 **동작과 접근성**(포커스 트랩, 키보드
내비게이션, ARIA)이다.

실제로 라이브러리성 컴포넌트가 필요한 곳은 적다: 다이얼로그(플래너·리뷰 패널),
드롭다운/팝오버, 체크박스, 툴팁 정도. 타이머 링·요일 핍·예산 게이지·🍅 도트·캘린더는
어차피 100% 커스텀이다.

검토한 선택지:

| 선택지 | 판정 | 이유 |
|---|---|---|
| shadcn/ui (스킨 전면 교체) | ✅ 채택 | 아래 Decision |
| HeroUI (구 NextUI) | ❌ | 기본 룩은 글래시에 가장 가깝지만 npm 의존성 스타일드 라이브러리 — 시안 토큰에 정확히 맞추는 마지막 20% 에서 테마 시스템과 싸우게 됨 |
| daisyUI | ❌ | `glass` 클래스는 CSS 만 제공, 필요한 것(동작·접근성)이 없음 |
| Base UI / React Aria 직접 | 차선 | 결과물은 채택안과 거의 같아지나, 다이얼로그·드롭다운 초기 뼈대를 직접 작성해야 함 |
| Aceternity / Magic UI | — | 대체재가 아닌 장식용 보완재. 필요 시 개별 도입 |

## Decision

**Tailwind CSS 를 스타일링 기반으로, shadcn/ui 를 동작 뼈대로 채택한다.
shadcn 컴포넌트는 구조·접근성(Radix 동작)만 취하고 스킨은 시안 토큰으로 전면 교체한다.**

- shadcn 의 가치는 룩이 아니라 "Radix 동작이 붙은 컴포넌트 코드가 **레포에 복사**된다"는
  점이다. 파일이 우리 것이므로 Tailwind 클래스를 토큰 기반으로 전부 갈아끼울 수 있다.
- Tailwind v4 는 CSS 변수 기반 테마(`@theme`)라 tokens.md 의 토큰을 1:1 매핑하기
  자연스럽고, "raw hex 직접 기입 금지" 규칙(design-system) 준수가 쉬워진다.

## Consequences

- (+) 다이얼로그·드롭다운의 접근성·키보드 동작을 공짜로 얻는다.
- (+) 컴포넌트 코드가 레포 안에 있어 커스터마이징에 상한이 없다.
- (−) "shadcn 이니까 UI 공짜"라는 기대는 성립하지 않는다 — 스킨은 전량 직접 작업.
- (−) shadcn 업데이트를 자동으로 받지 못한다 (복사 방식의 본질적 트레이드오프).
- 시각 값은 반드시 토큰 이름으로만 기술한다. 기능 문서와 충돌 시
  [design-system/principles.md](../../design-system/principles.md) 가 이긴다.
